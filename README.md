# Match Defender MVP

Первый playable-прототип идеи **match-3 + defense** на React + PixiJS + Zustand + TypeScript.

## Уже работает

- один PixiJS canvas, renderer WebGL;
- поле 6×6;
- 4 типа фишек: огонь, лёд, молния, щит;
- swap соседних фишек;
- невалидный ход откатывается;
- совпадение 3/4/5+ даёт 1/2/3+ зарядов;
- каскады после падения фишек;
- стартовое поле без готовых троек и с минимум одним возможным ходом;
- если ходов нет — автоматическое бесплатное перемешивание;
- 3 волны мобов;
- мобы идут к замку и наносят урон;
- ручное использование накопленных заклинаний;
- победа / поражение / рестарт.

## Заклинания сейчас

- 🔥 Огонь — урон нескольким ближайшим к замку мобам.
- ❄ Лёд — замедляет всех мобов на 2.5 сек.
- ⚡ Молния — сильный урон трём ближайшим мобам.
- ✚ Щит — восстанавливает HP замка.

Баланс временный — сейчас проверяем игровой цикл.

## Запуск

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

## Проверка ревизии

- версии зависимостей сверены; Vite зафиксирован на существующей ветке `^8.2.2`;
- заклинания больше не тратят заряд без полезной цели;
- молния рисует эффект до удаления убитых целей;
- async match-3 операции отменяются при reset/destroy;
- Pixi Application уничтожает сцену один раз без double-destroy.
